# Bingo Bloom art list

Made for Adobe Firefly (firefly.adobe.com). Every prompt already includes the house style, so all the pictures match.

## How to use it
1. Copy a prompt and paste it into Firefly's text box.
2. Set the shape (aspect ratio) shown for that section.
3. Make a few versions and download the best one.
4. For landmarks and icons, remove the background with Adobe Express's free background remover (adobe.com/express, Remove background) and save as PNG.
5. Rename the file to the name shown (for example `lobby-paris-map.png`) and upload it to the `art` folder of the bingo-game repository, or send it to Claude.

Never type another game's name (like Bingo Frenzy) into the tool. Check Firefly's current terms allow commercial use when you sign up.

**House style (already in every prompt):** Glossy 3D cartoon mobile game art, soft rounded shapes, plum purple and warm gold accents, cream highlights, bright cheerful sunlight, rich detail, clean edges, centered, no text, no logos.
